# Eines digitals Rockin

Portada que recull les eines digitals de Rockin per aprendre música tocant en grup.

👉 https://rockin-cat.github.io/

Les eines noves publicades amb GitHub Pages a l'organització apareixen automàticament a l'apartat «Noves eines».

Materials sota llicència Creative Commons BY-NC-SA 4.0 · Rockin.cat SCCL

Les captures de cada eina són a `captures/` (800×500, JPG). Per afegir-ne una de nova: desa-la amb el nom del repositori i afegeix el nom a la llista `SHOT` de l'`index.html`.
